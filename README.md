# QRprint

**免安装的 Excel 批量二维码标签打印工具。** 打开网页 → 选 Excel → 直接打印，整个过程不需要安装任何软件，数据也不会离开你的电脑。

### 👉 立即使用：<https://foodsaid.github.io/QRprint/>

> 也可以点右上角 **Code → Download ZIP**，解压后双击 `index.html` 本地打开，效果完全一样（连网络都不需要）。

---

## 特点

| | |
|---|---|
| **零安装、零依赖** | 整个工具就是一个 `index.html`，不需要 Node、Python、Excel 宏或任何插件 |
| **完全离线** | 页面用 CSP 禁止了一切网络请求。Excel 只在你本机的浏览器内存里解析，不上传、不落盘、不留存 |
| **自动识别表头** | 认得 `Item No.` / `物料号` / `料号` 等几十种中英文写法，SAP B1 库存导出可直接丢进去 |
| **自动去重合计** | 按「物料号 + 你勾选的字段」去重，库存列自动求和，多仓库合并显示 |
| **两种出纸方式** | A4 一页多枚（带等距裁切线，切刀不会错位）／标签打印机一枚一页（含 30×20 ~ 100×150 常用尺寸与自定义） |
| **批量筛选** | 仓库、库存 >0、条数范围，以及一次粘贴几百个物料号做精确 / 模糊匹配（并告诉你哪几个没找到） |
| **深浅色主题** | 跟随系统，也可手动切换 |

扫码结果 **= 物料号**，方便直接对接 WMS / 盘点 App。

## 使用方法

1. **载入 Excel** —— 点击或拖放 `.xlsx` / `.xls` / `.csv`（≤ 60 MB）。
2. **勾选标签上要显示的字段** —— 物料号必选；其余列载入后会自动列出，勾选的字段同时参与去重。
3. **选纸张与版式** —— A4 多枚一页，或标签纸一枚一页。
4. **筛选出这次要打的范围**，右侧实时预览，确认后点右上角 **打印**。

### 打印对话框里请务必检查

- 边距 → **无 / 默认**
- **关闭**页眉页脚
- **勾选**「背景图形 / Background graphics」——否则裁切线不会出纸
- 标签打印机：纸张尺寸选你实际的标签规格，缩放设为 **100% / 实际大小**

## 对 Excel 的要求

只要表格里有一列是物料号就行，表头在前 30 行内任意位置都能找到。以下列会被特殊对待：

| 用途 | 可识别的表头写法（大小写、空格、`.`、`_`、括号均忽略） |
|---|---|
| **物料号**（必需，二维码内容） | `Item No.` `ItemCode` `ItemNumber` `物料号` `物料编号` `物料代码` `项目编号` `品番` `料号` `编码` |
| 描述（默认勾选） | `Item Description` `Description` `ItemName` `物料描述` `描述` `品名` `物料名称` `名称` |
| 仓库（用于筛选与合并） | `Warehouse Code` `Warehouse` `WhsCode` `仓库` `仓库代码` `仓库编号` `库位` |
| 库存（自动求和） | `In Stock` `Stock` `OnHand` `Qty` `Quantity` `库存` `现有量` `在库` `库存量` |

其余列会原样列出，可自由勾选显示。多个工作表会一起解析。

**上限：** 单文件 60 MB、解析 200,000 行、预览 2,000 枚（超出请用筛选或条数范围分批打）。

## 隐私与安全

这类工具最常见的顾虑是「我的物料清单会不会被传走」。本项目的做法是从机制上排除这种可能：

- 页面头部的 `Content-Security-Policy` 设为 `default-src 'none'; connect-src 'none'`，
  **浏览器层面禁止**任何 fetch / XHR / WebSocket / 外链资源，图片只允许本地生成的 `data:` 二维码。
- 没有任何 CDN、字体、统计、埋点。GitHub Pages 只负责把这一个 HTML 文件发给你。
- Excel 解析与二维码生成都在你的浏览器里完成，全程只在内存中，页面一关就没了。
- 所有以 Excel 内容为键的字典使用无原型对象，表格里的文本一律通过 DOM 文本节点写入（不用 `innerHTML`），不存在原型污染或 HTML 注入。

不放心的话，把仓库下载下来断网双击打开即可 —— 功能一模一样。

## 二次开发

仓库里只有一个 `index.html`，内部按顺序分成四段，都有中文注释标注：

| 段落 | 内容 |
|---|---|
| `<style>` 上半部分 | 界面外观（设计变量、顶栏、侧栏、控件），可自由改 |
| `<style>` 下半部分 | **标签排版引擎** `.a4page` / `.grid` / `.cell` / `@media print`，尺寸单位与 JS 中的计算一一对应，改动会直接影响出纸效果 |
| 内联依赖 1/2 · 2/2 | [SheetJS xlsx](https://sheetjs.com) 0.20.3（Apache-2.0）与 [qrcode.js](http://www.d-project.com/) by Kazuhiko Arase（MIT），原样内联，未做修改 |
| 应用逻辑 | 解析 → 去重聚合 → 筛选 → 渲染。排版计算集中在 `renderA4()` 与 `renderLabels()` |

之所以内联成单文件而不是拆成 `assets/` + `vendor/`：这样用户下载后双击就能用，
拆开后在 `file://` 协议下 Chrome 会把来源视为不透明源，CSP 的 `script-src 'self'` 会拦掉外部脚本。

调整二维码容错等级或版本，改应用逻辑开头的 `QR_EC` / `QR_TYPE`；
各项上限见同处的 `MAXPREVIEW` / `MAXROWS` / `MAXFILE` / `MAXCACHE` / `MAXTEXT`。
